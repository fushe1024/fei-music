# 菲菲音乐

菲菲音乐是一个桌面端的音乐 Web 应用：可以浏览推荐歌单、歌单分类、排行榜与歌手，搜索歌曲与 MV，
并直接在页面里播放音乐和 MV，配套全屏播放页、逐字歌词、播放列表面板与三种播放模式。

## 功能

| 模块   | 能力                                                                                                     |
| ------ | -------------------------------------------------------------------------------------------------------- |
| 推荐   | 推荐歌单、新歌速递（3 列 9 首）、新碟上架（6 列），两个「更多」入口进入「新歌新碟」页                     |
| 歌单   | 标签行（热门标签 + 更多分类面板）与分类筛选，上拉分页，卡片进入歌单详情                                  |
| 排行榜 | 全部榜单渲染成渐变卡片，封面缺失时用内置色板兜底，点卡片进入对应榜单的歌单详情                            |
| 歌手   | 地区 / 性别 / 热门 / `#` / A–Z 索引，每页 50 条上拉加载；歌手详情展示头像、单曲数与热门单曲，可一键播放全部 |
| MV     | 推荐 / 最新 / 独家推荐 / 全部四段（地区、类型、排序筛选 + 上拉加载），详情页可播放并切换清晰度            |
| 搜索   | 头部输入即时建议（命中词高亮、清空、键盘选择），结果页五个 tab：单曲 / 歌单 / 专辑 / 歌手 / 视频          |
| 播放   | 播放条与全屏播放页、逐字歌词高亮、播放列表面板、顺序 / 单曲循环 / 随机三种模式、VIP 标注、轻提示          |
| 详情页 | 歌单详情、歌手详情、MV 详情，共用同一套歌曲表格与卡片，带骨架屏、空态与错误重试                            |

## 技术栈

| 方向     | 选型                                                                                                        |
| -------- | ----------------------------------------------------------------------------------------------------------- |
| 构建     | Vite 8 + React 19 + TypeScript                                                                              |
| 路由     | react-router 7 **Data 模式**：`createBrowserRouter` 对象式路由 + `RouterProvider`（不使用 `<Routes>` 标签） |
| 全局状态 | **zustand**（播放状态、队列、播放模式）                                                                     |
| 组件库   | shadcn/ui（Radix UI + Tailwind v4 + CVA）                                                                   |
| 样式     | SCSS（设计变量 + BEM 命名，按组件 / 页面就近组织）                                                          |
| 图标     | lucide-react                                                                                                |
| 视频播放 | **Video.js v10**（React 包为 `@videojs/react`，npm 上的 `video.js` 仍是 8.x）                                |
| 代码检查 | oxlint                                                                                                      |

## 快速开始

```bash
pnpm install
pnpm dev        # 开发预览（默认 http://localhost:5173）
pnpm build      # tsc -b && vite build
pnpm lint       # oxlint
```

> 运行配置（服务地址、超时、来源 IP 等）放在根目录 `.env`，改完需要重启 dev server。
>
> `pnpm-workspace.yaml` 中的 `allowBuilds` 允许 `@parcel/watcher` 执行安装脚本，
> 否则 pnpm 11 会在运行任何脚本前因「已忽略构建脚本」报错。

## 页面与路由

| 路径            | 页面                                       |
| --------------- | ------------------------------------------ |
| `/`             | 重定向到 `/recommend`                      |
| `/recommend`    | 推荐                                       |
| `/playlist`     | 歌单                                       |
| `/playlist/:id` | 歌单详情（推荐 / 歌单 / 榜单卡片都跳这里） |
| `/rank`         | 排行榜                                     |
| `/artist`       | 歌手                                       |
| `/artist/:id`   | 歌手详情（列表与搜索结果点头像进入）       |
| `/discSong`     | 新歌新碟（新歌速递 / 新碟上架）            |
| `/mv`           | MV                                         |
| `/mv/:id`       | MV 详情                                    |
| `/search`       | 搜索结果                                   |
| `*`             | 404                                        |

路由用对象数组声明，配合 `handle` 挂页面元信息（布局组件据此写入 `document.title`）；
顶层路由带错误边界，渲染异常时展示错误页而不是白屏。

## 功能细节

### 播放

- **真实播放**：播放状态由单例音频元素驱动，进度、时长、播放 / 暂停都来自音频事件再写回全局状态，
  组件只订阅状态，不直接操作音频元素。
- **按需加载**：只有点击播放某一首时才去取这一首的播放地址，不做批量预热；加入队列不会提前加载。
- **不可播放的曲目**：未登录或版权受限时取不到地址，播放条会提示「该歌曲暂时无法播放（可能需要会员）」
  并保持暂停，不会卡在加载中，也不会把提示写进歌手那一行。
- **受限不切歌**：点击受限曲目时，取到地址才切换播放器；取不到就保持原样，当前歌曲继续播放。
- **VIP 标注**：列表里受限曲目的歌名后跟一个主色描边的 `VIP` 标签，与能否真正播放保持一致。

### 播放列表与播放模式

播放条（以及全屏播放页）的列表按钮会打开播放列表面板：标题显示「歌曲｜共 N 首」，正在播放的一行高亮，
悬停出现喜欢 / 更多操作（下一首播放、立即播放、从列表移除），右上角可清空，`Esc` 或点击面板外收起。

播放模式按钮按「顺序播放 → 单曲循环 → 随机播放」轮换，播放条与全屏页共用同一份状态：

- **顺序播放**：下一曲往后走一格，播完最后一首自动结束；上一曲往前一格，已在第一首则停住不动；
- **单曲循环**：上一曲 / 下一曲都是从头重播当前这首；
- **随机播放**：下一曲随机挑一首并避开最近播放过的 8 首（队列较小时自动放宽），
  上一曲回到真正播放过的上一首，没有历史才随机。

### 歌词

全屏播放页展示歌词，逐字高亮用动画帧直接写样式变量，不触发组件重渲染；
当前行滚动到内容区垂直中心（内容区顶部与播放条之间的中点），顶部与底部用遮罩淡出。
普通歌词与逐字歌词并发获取，先到的先显示，逐字数据到达后自动替换；
老歌没有逐字数据时按字数均分补齐，保证逐字高亮对所有歌都生效。

### 歌单、歌手与排行榜

- **歌单页**：标签行为「全部 + 热门标签 + 更多分类」，点标签重新筛选并回到内容区顶部；
  「更多分类」面板浮在标签行下方（绝对定位，不撑开布局），打开时自动定位到当前选中标签所属分类；
  标签行滚动时吸附在顶栏下沿。
- **上拉加载**：底部哨兵提前一屏预加载下一页，加载中显示主色弧线，失败可点击重试，到底显示「没有更多了」；
  切换筛选不会闪现旧数据，跨页重复项会去重。
- **歌手页**：热门、`#`、A–Z 与两排筛选都是同一份列表的不同筛选条件；
  地区中的「日韩」会合并两个地区的取数结果并按 id 去重。
- **排行榜页**：榜单卡片用榜单封面作底图，缺失时用内置渐变兜底并折行显示名称；悬停出现播放键。

### MV

MV 列表用 16:9 缩略图卡片，角标显示播放量与时长；「全部」带地区、类型、排序三组筛选与上拉加载。
详情页使用 Video.js v10 播放，按可用清晰度渲染 1080P / 720P / 480P / 240P 切换，
下方还有「更多 MV」。若某个 MV 的详情取不到，会用列表带过来的信息兜底展示名称与歌手，
播放区降级为「该 MV 暂时无法播放」。

### 搜索

头部输入框 260ms 防抖给出建议（命中词高亮、清空按钮、上下键选择、回车搜索，兼容输入法组合态）；
结果页标题为「关键词 的相关结果」，五个 tab 分别渲染单曲表格与歌单 / 专辑 / 歌手 / 视频卡片，
单曲 tab 额外的「播放全部」会优先挑第一首可播的曲目。

## 主题配色

主色为蓝色系，色阶取自 **Cyan / Sky / Blue** 三套 11 级色板（50 ~ 950），定义在 `src/styles/globals.css`。
切换方式：改 `index.html` 上的属性即可整站换色，无需改任何组件：

```html
<html lang="zh-CN" data-brand="blue">
  <!-- blue（默认） / sky / cyan -->
</html>
```

也可以在运行时切：`document.documentElement.dataset.brand = 'sky'`。

语义令牌全部从色阶派生，便于整体调整：

| 令牌                                | 取值                                   | 用在哪                                               |
| ----------------------------------- | -------------------------------------- | ---------------------------------------------------- |
| `$brand` / `--brand`                | `brand-500`                            | 登录按钮、播放键、进度条、链接与图标 hover、VIP 描边 |
| `$brand-dark`                       | `brand-600`                            | 上述元素的 hover 态                                  |
| `$brand-light`                      | `brand-50`                             | 选中胶囊底色、「更多分类」底色                       |
| `$brand-border`                     | `brand-200`                            | 胶囊描边、标签描边                                   |
| `--primary` / `--ring` / `--accent` | `brand-500` / `brand-300` / `brand-50` | shadcn 组件（Button、Tabs、Slider、Tooltip…）        |

- SCSS 侧 `src/styles/_variables.scss` 里的 `$brand*` 直接引用 CSS 变量，颜色只有一处定义。
- 侧栏选中态、面板底色等是中性灰 / 淡紫灰，未随主色变化，保持版式一致。
- 顶栏 logo 与 favicon 是位图（`public/assets/brand/`），换主色时不会自动改色，需要换图或加
  `filter: hue-rotate(...)`。

## 布局与滚动

页面本身不滚动，只有主内容区滚动：

```
.app        height:100%; overflow:hidden
├─ Header   固定，top 0，高 78
├─ Sidebar  固定，left 0，宽 195，上 78 / 下 78
├─ .app__main  固定，top 78 / bottom 78 / left 195 / right 0，
│              overflow-y:auto + scrollbar-gutter:stable  ← 唯一滚动容器
└─ PlayerBar 固定，bottom 0，高 78
```

- `scrollbar-gutter: stable` 常驻 8px 滚动条槽，右侧内边距取 32px（32 + 8 = 左侧 40），
  内容区始终是 `235 ~ 1400`，滚动条只出现在主内容区右缘（顶栏之下、播放条之上）。
- 切换路由时主内容区会自动回到顶部。
- 全屏播放页与播放列表面板都是覆盖层，不参与布局。

## 设计还原

- 设计稿宽 2160px，对应 **1440×786** 的 CSS 视口（DPR 1.5），尺寸按 `÷1.5` 换算后写入 SCSS 变量。
- 关键版式（顶栏 78、侧栏 195、播放条 78、封面网格 6 列间距 20、榜单卡片 3 列等）按设计稿量取，
  `src/styles/_variables.scss` 是唯一来源，实测偏差在 3px 以内。
- 封面、头像、榜单缩略图与品牌图均为项目自有素材，放在 `public/assets`。

## 说明与限制

- 未登录 / 非会员状态下部分曲目无法播放，会给出提示并保持暂停，不会卡在加载中。
- 歌单在未登录时返回的曲目可能不完整，页面以歌单标注的总数为准。
- 个别 MV 的详情取不到，此时详情页用列表信息兜底展示，播放区提示暂时无法播放。
